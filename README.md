## Library Management System

# Overview

This project is a console-based Library Management System developed in Java as part of the Bring Your Own Project (BYOP). It is designed to simplify basic library operations such as managing books and student records.

The system provides a structured way to handle tasks that are often managed manually in small institutions.

# Problem Addressed

In many small libraries, book records and student details are maintained using manual registers. This can lead to errors, difficulty in tracking issued books, and inefficient record management.

This project aims to provide a simple and organized solution using core Java programming concepts.


# Features

- Add new books  
- Register students  
- Issue books (with availability check)  
- Return books  
- View available books  
- Menu-driven console interface  


# Technologies Used

- Java  
- Object-Oriented Programming (OOP)  
- ArrayList (Java Collections Framework)


# Project Structure

- 'Book.java' – Represents book details  
- 'Student.java' – Represents student details  
- 'Library.java' – Handles library operations  
- 'Main.java' – Contains the main method and menu interface
